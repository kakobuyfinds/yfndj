How to use the spreadsheet

  1. Check the listing and agent options. Open the CAFANS product page. If you plan to use PikoBuy, check whether it accepts the original seller link before adding funds or placing an order.
  2. Compare measurements. For tops, compare chest width and garment length with a piece you own. For shoes, check whether the seller's chart refers to foot length or insole length.
  3. Review warehouse photos when available. Match the color, size label and visible details to the variant you ordered. Check the seller's return window while the parcel is still at the warehouse.
  4. Compare quotes for the same parcel. Use the same destination, packed dimensions and weight for each quote. Check whether the carrier bills by actual weight or dimensional weight.

PikoBuy spreadsheet FAQ

What is a PikoBuy spreadsheet?

It is a product directory for people researching purchases through a shopping agent. This independent guide uses selected CAFANS listings. Check agent support for the specific seller link before ordering.

Do the USD prices include international shipping?

The catalog shows estimated item prices. Add domestic delivery, agent fees, international shipping, and any applicable taxes to compare total costs.

Where can I see QC photos?

The images in this catalog are CAFANS listing photos. If your agent offers warehouse QC photos, review the set for your exact item and variant before approving shipment.

What should I do if a listing is unavailable?

Search CAFANS by the item name and compare the seller, measurements and available variants before saving a replacement link.
